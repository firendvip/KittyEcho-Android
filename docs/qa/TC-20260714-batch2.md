## 一、正向 + 边界（8 项改动）

### 改动1 · 设置页版本行

**B2-001 版本行显示与格式** · P1
- 前置：打开 App 设置页（MinimalSettingsScreen），滚动到最底部。
- 步骤：查看最底部版本行。
- 预期：显示 `v{versionName}({versionCode})·{sha}` 形态的动态文本（debug 版 versionName 含 `-debug+sha` 后缀属正常）；非硬编码占位符、非空。

**B2-002 版本行与装机包实际一致** · P0
- 前置：同上；终端可用 adb。
- 步骤：`adb shell dumpsys package com.wordtaker.keyboard.debug | grep -E "versionName|versionCode"`，与设置页版本行逐字段比对。
- 预期：versionName、versionCode、git sha 三者与装机包完全一致，无漂移。

### 改动2+7 · 字母键 24sp / 特殊键 22sp 不截断

**B2-003 字母键字号 24sp 观感** · P1
- 前置：任意输入框拉起键盘，日间主题。
- 步骤：截图 QWERTY 字母区，与旧版（22sp）对比或量测字母字高像素。
- 预期：字母明显大于改前；26 键字号一致；无重叠、无溢出键帽。

**B2-004 特殊键 22sp 且「换行」不截断** · P0
- 前置：中文布局拉起键盘。
- 步骤：逐个检查特殊键标签：换行、删除、?123、中/英、空格、符号键；截图放大核对。
- 预期：特殊键仍为 22sp（视觉小于字母键）；「换行」两字完整显示，无省略号、无裁切；其余标签键均不截断。

**B2-005 夜间主题同步生效** · P2
- 前置：系统切深色模式（`adb shell cmd uimode night yes`），拉起键盘。
- 步骤：重复 B2-003/B2-004 的观察。
- 预期：floris_night 主题下字母 24sp / 特殊键 22sp 同样生效、不截断。测完恢复 `night no`。

### 改动3 · 四态切换零跳动

**B2-006 四态窗口顶边恒等（像素判定）** · P0
- 前置：拉起键盘（键盘态）。
- 步骤：依次进入四态：①普通键盘 ②设置面板（顶栏猫钮）③历史面板 ④手写面板；每态截图，量测 IME 窗口顶边 y（或 `dumpsys window | grep -i inputmethod` 取 frame）。
- 预期：四态顶边 y 全部相等（基准约 1431，彼此差 0px）；设置/历史面板高=keyboardUiHeight+15dp、手写墨迹区=keyboardUiHeight-48dp 的换算与实测一致。

**B2-007 快速来回切换无跳动** · P0
- 前置：键盘态。
- 步骤：键盘↔设置面板快速来回切换 10 次（短 swipe 点猫钮/返回），再键盘↔手写快速切换 10 次；观察截图序列与 logcat。
- 预期：全程顶边 y 不变，无窗口高度抖动、无白闪、无崩溃/ANR。

**B2-008 120ms Crossfade 过渡观感** · P2 · 需真机（模拟器可录屏粗验）
- 前置：键盘态。
- 步骤：`adb shell screenrecord` 录制一次键盘→设置面板切换，逐帧看。
- 预期：内容淡入淡出（约 120ms），无瞬间硬切、无中间空白帧；真机肉眼确认流畅。

### 改动4 · 顶栏猫头像设置钮

**B2-009 顶栏猫钮外观** · P1
- 前置：键盘态。
- 步骤：截图放大顶栏设置钮。
- 预期：显示小猫头像（ic_brand_cat）置于白色圆圈内，圈约 30dp；不再是旧齿轮/旧图标。

**B2-010 猫钮功能与设置面板猫钮尺寸** · P0
- 前置：键盘态。
- 步骤：①短 swipe 点顶栏猫钮 → 应打开设置面板；②截图量测设置面板内猫钮圆圈；③再点返回回键盘。
- 预期：点击打开设置面板功能不变；面板内猫钮圈约 25dp，未被 IconButton 最小 48dp 撑大（周围无异常大空白，历史撑大问题不复现）。

### 改动5 · 录音猫居中 + 音符减半

**B2-011 录音猫垂直居中（量化）** · P0

**B2-012 音符尺寸减半** · P2

- 步骤：截图量测音符符号尺寸，与旧版对比（旧 11-15 单位，新 5.5-7.5）。
- 预期：音符约为旧版一半大小，不遮挡猫，动画正常。

### 改动6 · 账户与额度 = App 内子页

**B2-013 入口为子页而非 Activity** · P0

- 预期：AccountScreen 以 App 内子页打开（同一 Activity，无新 Activity 入栈）；页面带返回箭头。

**B2-014 返回箭头回设置** · P1

**B2-015 系统返回键回设置** · P1

**B2-016 额度信息拉取** · P1 · 需真机（依赖真实登录态；模拟器有登录态则可验）

## 二、回归（既有功能不得回归）

**B2-019 连续听写不自动结束** · P0 · 需真机（真实麦克风+转写链路）
- 前置：真机、已登录、网络可用。
- 步骤：进录音面板说一句话，停顿 5s 以上不点击；再说第二句；最后手动点击结束。
- 预期：停顿期间录音**不自动结束**；两句均转写上屏；仅手动点击才返回键盘。

**B2-020 音量滑杆** · P1 · 需真机（需实时音量反馈；模拟器仅可验 UI 存在与拖动）
- 前置：录音面板打开。
- 步骤：拖动音量滑杆至不同位置。
- 预期：滑杆可拖动、位置保持、提示音量随之变化（真机验听感）。

**B2-021 中文滑行输入** · P0
- 前置：中文键盘态。
- 步骤：在字母区做连续滑行轨迹（如 n→i→h→a→o），观察候选。
- 预期：滑行轨迹渲染正常，出候选「你好」等，点按候选上屏；无崩溃。

**B2-022 手写输入** · P0
- 前置：切到手写面板。
- 步骤：①量测墨迹区高度=keyboardUiHeight−48dp；②在墨迹区书写「猫」；③点候选上屏。
- 预期：墨迹区高度符合新值且可正常书写识别（识别精度真机复核）；上屏成功；与改动3 共存无跳动。

**B2-023 云词库开关** · P1
- 前置：设置面板/App 设置中找到云词库开关。
- 步骤：开→关→开各一次，每次后打几个词观察候选来源；观察 logcat 网络请求。
- 预期：开关状态持久；开时云候选参与、关时不发词库请求；切换不崩溃。

**B2-024 D-1 冷启动 0 ANR** · P0
- 前置：`adb shell am force-stop com.wordtaker.keyboard.debug`（勿 pm clear）。
- 步骤：点输入框首次拉起键盘，计时至键盘可交互；`adb shell dumpsys activity anr` / logcat 查 ANR；重复 1 次。
- 预期：冷启动无 ANR、无「无响应」弹窗；键盘 3s 内可用。

**B2-025 D-2 候选快速点按 30s** · P0
- 前置：中文键盘态。
- 步骤：连续 30 秒快速输入拼音并点按候选（短 swipe，尽量快节奏），穿插翻页。
- 预期：全程无崩溃、无 ANR、无候选错位/卡死；上屏内容与点按一致。
