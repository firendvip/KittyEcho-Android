## 平台副作用观察（供产品评估，非判定）

1. **媒体不 duck 不暂停**：本 App 不请求 audio focus，录音中音乐照常播放（识别靠 AEC 扛住）——体验上无打断，但嘈杂环境识别率依赖 AEC 上限。
2. **小音量全抑（新增，最重要）**：Mac 音量 40（模拟小声/远场）3/3 轮 0 字且不触发 endpoint（用户视角=说了没反应、录音一直转直到手停）；阈值在 40–55 档间。建议评估：通话通路 NS 强度是否可调 / 起始增益预热 / 对「无声超时」加提示。
3. **通知**：录音中通知正常入栈不崩溃；通知音可闻性因 shell 通道静音无法真实定性。
4. **并发录音互不打断**（vivo Android 14 实测）：他 App 先占 mic 时本 App 仍取得可用音频流。
5. **状态栏无「通话中」样式**，仅标准麦克风指示。

## 遗留观察对照（R3 延续）
