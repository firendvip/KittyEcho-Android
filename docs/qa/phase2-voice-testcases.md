# 弦外小猫 Android 输入法 · 阶段2（语音一体化）测试用例

- **被测工程**：KittyEcho-Android（FlorisBoard fork 中文输入法）
- **被测改动**：
  1. ASR 换为流式 Zipformer multi-zh-hans int8（OnlineRecognizer，边说边出 partial；rule2=1.2s 说后静音自动定稿、rule1=2.4s 纯静音、rule3=60s 上限）；模型内置 `assets/models/zipformer-zh/`（~72.5MB），升级时自动清理旧 SenseVoice 目录；ModelDownloader 4 文件下载兜底（hf-mirror→HF）。
  2. 语音流：「点击说话」→ 录音 → 实时字幕（底部最多 2 行）→ endpoint 或手点结束 → 定稿进输入框 → 可键盘改字 → 可选云端润色（RelayClient）→ commitText。
  3. 语音↔键盘无缝切换、麦克风权限引导（MicPermissionActivity）。
  4. RealPolisher role→mode 对齐 Mac 契约（normal→normal / gaoeq→gaoeq / 其余→copywriting）。
- **环境标注**：【模拟器可测】= Android Studio 模拟器（可用宿主麦克风虚拟音频）即可判定；【须真机】= 涉及真实中文语音识别质量（CER）、端点时序、延迟、音频占用、发热/功耗，必须真机。
- **通用前置**（除非用例另述）：已安装最新阶段2 APK；已在系统设置启用并切换到弦外小猫输入法；已授予麦克风权限；模型已就位（首启 assets 自动安装完成）；处于任一可输入 App（如备忘录/微信）文本框。
- **日志观察**：`adb logcat -s VoiceVM RealSpeechEngine Zipformer ModelAssetInstaller ModelDownloader`

## 一、正向流程

### P2-001 点击说话进入录音态 — P0【模拟器可测】
- **前置**：通用前置；键盘处于猫面板待机（顶条显示「点击说话」药丸）。
- **步骤**：点按「点击说话」药丸。
- **预期**：播放开始提示音（设置开启时）；进入录音界面（猫出现、电平动画跳动）；顶条候选/工具栏按设计隐藏；无 ANR/崩溃。

### P2-002 边说边出字（流式 partial 字幕） — P0【须真机】
- **前置**：通用前置。
- **步骤**：开始录音后用正常语速连续说一句 5~10 秒中文（如「今天下午三点我们在会议室开个短会讨论一下方案」），说话过程中观察底部字幕。
- **预期**：说话过程中字幕**实时**逐步出现并随语音增长/修正（非结束后一次性出现）；字幕位于底部「取消」上方居中；内容与所说大致一致。

### P2-003 endpoint 1.2s 静音自动定稿 — P0【须真机】
- **前置**：通用前置。
- **步骤**：录音中说一句话，然后闭嘴保持安静，用秒表估测从停止说话到自动定稿的时长。
- **预期**：约 1.2~2 秒内自动结束录音（等价手点结束）；进入识别→（润色）→文本 commit 进输入框；播放结束提示音；logcat 出现 `endpoint detected -> auto stop`。

### P2-004 手动点击结束定稿 — P0【须真机】
- **前置**：通用前置。
- **步骤**：录音中说一句话，不等静音，说完立刻点击录音区（onTap 结束）。
- **预期**：立即进入识别态；最终文本（含字幕已出内容+尾部音频）完整 commit 进输入框，无丢尾字。

### P2-005 云端润色成功上屏 — P0【须真机】
- **前置**：通用前置；网络正常；润色开启，AI 角色=normal。
- **步骤**：说一句带口语赘词的话（如「嗯那个就是我想说这个方案还行吧然后细节再说」），定稿。
- **预期**：状态经过 识别→润色→成功；上屏文本为润色后的通顺文本（去赘词）而非原始转写；历史记录同时保存原文+润色文。

### P2-006 role→mode 契约映射 — P1【模拟器可测】
- **前置**：通用前置；可抓包（代理/relay 日志）或读 RelayClient 请求日志。
- **步骤**：分别把 AI 角色设为 normal、gaoeq、vibecoding（及任一未知/其他角色），各完成一次语音润色，检查发往 relay 的 `mode` 字段。
- **预期**：normal→`normal`；gaoeq→`gaoeq`；vibecoding 及其余任何角色→`copywriting`。与 Mac 端契约一致。

### P2-007 历史记录写入 — P1【须真机】
- **前置**：通用前置。
- **步骤**：完成一次成功语音输入；打开键盘历史页（或历史 Activity）。
- **预期**：新增一条记录，含原始转写与润色结果，时间正确；minimal 关闭时曾出现「已写入历史」toast。

### P2-008 定稿后键盘改字（语音→键盘无缝衔接） — P0【须真机】
- **前置**：通用前置。
- **步骤**：语音上屏一句话 → 切回拼音键盘 → 移动光标到句中 → 删除 2 个字并用拼音输入替换 → 再次点「点击说话」补说一句。
- **预期**：键盘编辑正常（候选、删除、光标都正常）；第二次语音文本追加在光标处；两种输入交替无卡顿、无状态错乱。

### P2-009 提示音成对播放 — P1【模拟器可测】
- **前置**：通用前置；设置中提示音开启。
- **步骤**：a) 正常完成一轮语音；b) 录音中点「取消」；c) 录音中点键盘图标切走。
- **预期**：三种路径均为 开始音+结束音 成对出现（取消/切走也播放结束音，保持对称）；提示音关闭时全程静音。

### P2-010 首启 assets 模型自动安装 — P1【模拟器可测】
- **前置**：全新安装（先卸载旧版）；首次启用键盘。
- **步骤**：安装启动后等待 ≤1 分钟；`adb shell run-as com.wordtaker.keyboard ls -l files/zipformer-zh/`。
- **预期**：目录含 4 文件（encoder.int8.onnx ~70MB、decoder.int8.onnx、joiner.int8.onnx、tokens.txt）+ `.installed_v2` 标记；期间无网络请求（断网也能完成）；随后语音功能可用。

### P2-011 外部入口触发录音 — P1【模拟器可测】
- **前置**：通用前置；键盘处于拼音打字面板。
- **步骤**：分别通过 a) 工具栏语音图标 b) 长按空格 c) CAT_VOICE 键，各触发一次。
- **预期**：三种入口均切到猫面板并**直接开始**录音；录音中再次触发外部入口不会把录音停掉（只开始、从不结束）。

### P2-012 成功动效与提示 — P2【模拟器可测】
- **前置**：通用前置；极简模式关闭。
- **步骤**：完成一次成功语音输入，观察结束瞬间。
- **预期**：busy→false 触发猫 sparkle 动画；出现「已写入历史」toast；约 1.2s 后自动回待机态。极简模式开启时不出该 toast。

## 二、边界

### P2-101 超长说话（60s 上限 rule3） — P1【须真机】
- **前置**：通用前置。
- **步骤**：连续不间断说话 70 秒以上（可念文章）。
- **预期**：不崩溃、不 ANR；在约 60s（rule3 硬上限）或静音时定稿；已出字幕内容不丢失；上屏文本完整（截至定稿点）。

### P2-102 极短点击（<0.5s 立即结束） — P1【模拟器可测】
- **前置**：通用前置。
- **步骤**：点「点击说话」后不出声立刻再点结束；重复 5 次。
- **预期**：每次都提示「未识别到语音」并回待机；不上屏空文本、不写历史；连点无状态卡死。

### P2-103 endpoint 抗误触发（短停顿 <1.2s） — P1【须真机】
- **前置**：通用前置。
- **步骤**：说前半句 → 停顿约 0.8~1.0 秒 → 继续说后半句 → 静音等待自动定稿。
- **预期**：短停顿**不**触发定稿，录音继续；最终一次性上屏完整前后两半句。

### P2-104 纯静音不误定稿（rule1 守卫） — P1【须真机】
- **前置**：通用前置；安静环境。
- **步骤**：点开始后全程不说话，静置 10 秒，然后手点结束。
- **预期**：静置期间**不**自动定稿（endpoint 需已出文字才生效，纯静音 2.4s rule1 不触发 UI 定稿）；手点结束后提示「未识别到语音」回待机。

### P2-105 连续多轮语音 — P1【须真机】
- **前置**：通用前置。
- **步骤**：连续完成 10 轮「说话→定稿→上屏」（混合自动定稿与手点结束）。
- **预期**：10 轮全部成功；字幕每轮从空白开始（不残留上一轮内容）；识别延迟无逐轮劣化；`adb shell dumpsys meminfo` 内存无持续增长（无会话泄漏）。

### P2-106 录音中切回键盘（丢弃语义） — P1【模拟器可测】
- **前置**：通用前置。
- **步骤**：录音中（已出部分字幕）点击键盘图标切回打字面板；随后用拼音正常打 5 个字。
- **预期**：录音被丢弃（不上屏、不写历史）、播放结束音、回 Idle；拼音打字、候选完全正常；再切回语音可正常开始新录音。

### P2-107 字幕 2 行截断 — P2【须真机】
- **前置**：通用前置。
- **步骤**：连续说 30 秒以上长内容，观察底部字幕区域。
- **预期**：字幕最多显示 2 行（超出按省略策略截断），不撑高/顶乱布局，不遮挡「取消」按钮；定稿上屏的文本仍是**全文**不受 2 行显示限制。

### P2-108 处理中背景点击守卫 — P1【模拟器可测】
- **前置**：通用前置。
- **步骤**：定稿后处于识别/润色（busy）阶段时，快速连点录音区背景 5 次。
- **预期**：点击全部被忽略（不开启新录音、不产生隐藏动作）；唯一可中断方式是「取消」按钮；流程正常走完上屏一次。

### P2-109 冷启动兜底批量解码 — P1【须真机】
- **前置**：全新安装完成模型安装后，杀掉键盘进程（`adb shell am force-stop com.wordtaker.keyboard`）。
- **步骤**：立即唤起键盘并在 ~2 秒内点「点击说话」说一句话（抢在 recognizer 预热完成前），手点结束。
- **预期**：录音期间可能无实时字幕（未开流式会话属预期）；stop 后走批量解码兜底，等待 ≤3s 仍能出字上屏；若模型 3s 内仍未就绪则提示「语音模型正在准备，请稍候」而非卡死。

### P2-110 录音中锁屏/切 App — P2【须真机】
- **前置**：通用前置。
- **步骤**：a) 录音中按电源键锁屏再解锁；b) 录音中切到桌面再切回原 App 唤起键盘。
- **预期**：两种情况均不崩溃；恢复后键盘状态一致（录音已被取消/复位则回待机可重新开始）；不出现「幽灵录音」（界面待机但麦克风仍占用）。

### P2-111 endpoint 与手点结束竞争 — P2【须真机】
- **前置**：通用前置。
- **步骤**：说完话后在约 1.2s 静音临界点**同时**手点结束（多试 5 次以命中竞争窗口）。
- **预期**：只走一次识别/润色/上屏（文本不重复 commit）；无崩溃、无卡在处理中。

## 三、异常

### P2-201 无麦克风权限首次引导 — P0【模拟器可测】
- **前置**：`adb shell pm revoke com.wordtaker.keyboard android.permission.RECORD_AUDIO`；唤起键盘。
- **步骤**：点「点击说话」→ 说话 → 结束（或等自动流程）。
- **预期**：弹出透明 MicPermissionActivity 承载的系统权限对话框（无可见过渡动画）；点「允许」后对话框消失回到原 App；再次点「点击说话」可正常录音出字。

### P2-202 拒绝权限不卡死 — P0【模拟器可测】
- **前置**：同 P2-201（权限已撤销）。
- **步骤**：触发权限弹窗后点「拒绝」；回键盘再点「点击说话」。
- **预期**：出现「需要麦克风权限」toast；UI 回待机不卡在录音/处理态；再次点击再次触发权限引导；全程无崩溃。

### P2-203 永久拒绝后行为 — P1【模拟器可测】
- **前置**：连续拒绝两次使系统不再弹框（Android 11+ 永久拒绝语义）。
- **步骤**：再点「点击说话」。
- **预期**：不崩溃；MicPermissionActivity 静默启动即结束；仍给出「需要麦克风权限」提示，用户可去系统设置手动授权后恢复正常。

### P2-204 麦克风被占用 — P1【须真机】
- **前置**：通用前置；先用另一 App 独占录音（如正在通话/其他录音 App 录制中）。
- **步骤**：点「点击说话」→ 说话 → 结束。
- **预期**：AudioRecord 打开失败时流式会话被回收（无泄漏）；结束后提示「未识别到语音」（空样本）；回待机；释放占用后重试可正常识别。

### P2-205 模型缺失走提示/兜底 — P0【模拟器可测】
- **前置**：`adb shell run-as com.wordtaker.keyboard rm -rf files/zipformer-zh`（含 `.installed_v2`）；不杀进程直接操作。
- **步骤**：点「点击说话」→ 结束。
- **预期**：不崩溃；提示「语音模型正在准备，请稍候」并触发 ModelRequired 事件（引导下载/重装流程）；后台从 assets 重装（或下载兜底）完成后语音恢复可用。

### P2-206 下载兜底源切换与完整性 — P1【模拟器可测】
- **前置**：删除模型目录且构造 assets 安装不可用场景（或直接单测/手测 ModelDownloader）；用 hosts/代理把 `hf-mirror.com` 指向不可达。
- **步骤**：触发模型下载；观察 logcat 与 `files/zipformer-zh/`。
- **预期**：hf-mirror 失败后自动切 huggingface.co 官方源；下载顺序 tokens→decoder→joiner→encoder；中途断网时 `.part` 临时文件被清理、`isDownloaded` 保持 false（不把半截文件当就绪）；4 文件齐且 encoder>30MB 后才判定就绪。

### P2-207 断网润色降级回 raw — P1【须真机】
- **前置**：通用前置；润色开启；开飞行模式前先确认模型已本地就绪。
- **步骤**：开启飞行模式 → 语音说一句话 → 定稿。
- **预期**：本地识别正常出字幕（离线 ASR 不依赖网络）；润色失败后**上屏原始转写**（不丢字、不报错弹窗）；流程不卡在「润色中」；历史仍写入。

### P2-208 润色超时 10s 降级 — P1【模拟器可测】
- **前置**：通用前置；用代理/防火墙让 relay 请求挂起不响应（丢包不拒绝）。
- **步骤**：语音一句话定稿，计时。
- **预期**：约 10s（POLISH_TIMEOUT_MS）后放弃润色，上屏原始转写；logcat 出现 `polish: timeout ... falling back to raw`；UI 不永久卡「润色中」。

### P2-209 录音中取消 — P0【模拟器可测】
- **前置**：通用前置。
- **步骤**：录音中（已出字幕）点「取消」按钮。
- **预期**：立即停止、播放结束音、回待机；**不**上屏任何文本、**不**写历史；输入框内容不变。

### P2-210 识别/润色中取消（越过挂起点守卫） — P1【模拟器可测】
- **前置**：通用前置；可用慢网放大润色窗口期。
- **步骤**:在「识别中/润色中」阶段点「取消」；重复 5 次。
- **预期**：每次都回待机且**绝不**上屏（含协程已越过挂起点的竞争场景，cancelled 守卫拦截 commit 与历史写入）；无重复文本、无崩溃。

### P2-211 半截/损坏模型文件 — P2【模拟器可测】
- **前置**：`adb shell run-as` 把 `files/zipformer-zh/encoder.int8.onnx` 截断为 <30MB（或替换为垃圾字节），保留其余文件与 marker。
- **步骤**：重启键盘进程后点「点击说话」→ 结束。
- **预期**：`isDownloaded` 判 false（尺寸校验），触发重装/下载兜底或「模型正在准备」提示；不因加载损坏 ONNX 而进程崩溃/闪退循环。

### P2-212 上屏瞬间焦点丢失 — P2【须真机】
- **前置**：通用前置。
- **步骤**：说话定稿后、润色返回前迅速切到无输入框界面（如按 Home），再回原输入框。
- **预期**：不崩溃；文本要么已 commit 进原输入框，要么安全丢弃（历史中仍可找回）；键盘再次唤起状态正常。

## 四、回归（阶段1 功能不受影响）

### P2-301 拼音打字与候选 — P0【模拟器可测】
- **前置**：通用前置；切到拼音键盘。
- **步骤**：输入「nihao」选候选「你好」；再连打一句 10 字长句（含分词候选翻页）。
- **预期**：出字、候选排序、翻页、选字全部与阶段1一致；无卡顿劣化。

### P2-302 符号/数字键盘 — P1【模拟器可测】
- **前置**：通用前置。
- **步骤**：切符号面板输入「，。？！@#」，切数字面板输入「12345」，再切回字母面板。
- **预期**：三面板切换与上屏正常；快捷符号条正常；无布局错乱。

### P2-303 主题不受影响 — P1【模拟器可测】
- **前置**：通用前置。
- **步骤**：在设置中切换 2~3 个主题/皮肤（含深浅色），每个主题下打字并走一轮语音界面。
- **预期**：键盘与语音面板（字幕、药丸、取消按钮）随主题正确着色，无透明/错色/黑块。

### P2-304 APK 无 SenseVoice 残留 — P1【模拟器可测】

### P2-305 升级清理旧模型目录 — P1【模拟器可测】
- **前置**：先安装旧版（SenseVoice 版）并确保 `files/sensevoice/` 存在（可 `run-as` 伪造该目录+大文件模拟）；`adb install -r` 覆盖安装新版。
- **步骤**：升级后启动键盘，等待安装器跑完；`adb shell run-as com.wordtaker.keyboard ls files/`。
- **预期**：`sensevoice/` 目录被自动删除（释放 ~228MB）；`zipformer-zh/` 就位；升级后语音直接可用，无需重新下载。

### P2-307 长按空格与语音入口不冲突 — P2【模拟器可测】
