# 弦外小猫键盘 · 夜间第4轮 QA 测试用例（TC-20260713-night4）

- **被测对象**：com.wordtaker.keyboard.debug（emulator-5554 已装并为默认 IME）
- **本轮改动范围**：① 提示音音量滑杆 ② 录音不自动结束（连续听写） ③ 录音界面小猫缩 10% ④ 键盘样式对齐 A55 基准图
- **环境限制**：模拟器无真实麦克风 → 依赖真实语音/endpoint 触发/实际响度的用例标 **BLOCKED(需真机)**，模拟器只验 UI 状态机部分。
- **通用前置**：键盘 App 已安装、已授予麦克风权限、已设为默认输入法；测试宿主用系统「信息」或任意带文本框的 App。
- **优先级**：P0=核心功能必过；P1=重要；P2=一般。

## 模块 A：提示音音量滑杆（tone_volume）

### N4-001 [P0] 滑杆显示条件与默认值
- 前置：首次进入（或未改过 tone_volume）。
- 步骤：打开 App 设置首页 →「提示音」卡；确认提示音开关为开。
- 预期：卡内出现音量滑杆；默认值 100（滑到最右/显示 100%）。

### N4-002 [P0] 音量 0% 完全不播提示音
- 前置：提示音开关开。
- 步骤：滑杆拖到 0 → 回键盘 → 触发一次会播喵叫的操作（进入/结束录音界面）。
- 预期：无任何喵叫等语音提示音（v=0 直接不播，非播放极小声）。响度人耳复核标 **需真机**；模拟器可经 logcat/音频焦点辅助判断不播。

### N4-003 [P1] 音量 50% 响度介于 0 与 100 之间
- 前置：提示音开关开。
- 步骤：滑杆调 50 → 触发喵叫；再调 100 触发一次对比。
- 预期：50% 有声且明显小于 100%。实际响度对比 **BLOCKED(需真机)**；模拟器仅验滑杆值保存与播放不报错。

### N4-004 [P0] 音量 100% 正常播放
- 步骤：滑杆调回 100 → 触发喵叫。
- 预期：提示音正常播放，与改动前音量一致。

### N4-005 [P1] 提示音开关关：滑杆隐藏且不播
- 步骤：「提示音」开关关闭 → 观察卡片；触发原本会播喵叫的操作。
- 预期：滑杆随开关隐藏；任何提示音均不播。再开开关，滑杆重现且保留原值。

### N4-006 [P0] 按键音不受滑杆影响
- 前置：系统/键盘按键音开启。
- 步骤：滑杆调 0 → 回键盘敲若干字母键。
- 预期：按键音照常发声（滑杆只作用喵叫等语音提示音）。

### N4-007 [P2] 滑杆值持久化
- 步骤：滑杆调 30 → 完全杀掉键盘 App 进程（勿 pm clear）→ 重新呼出键盘并进设置。
- 预期：滑杆仍为 30；提示音按 30% 播放。

## 模块 B：录音不自动结束（连续听写）

### N4-008 [P0] 停顿 >1.2s 不退出录音 — BLOCKED(需真机)
- 前置：进入录音界面，正常收音。
- 步骤：说一句话 → 静默 2~3s → 观察界面。
- 预期：该句定稿润色上屏；录音界面**不退出**，phase 保持 Recording，字幕清空继续听。
- 备注：endpoint 需真实语音触发；模拟器仅可验进入录音后界面长时间保持 Recording 不自灭。

### N4-009 [P0] 多次停顿连续多段按序上屏 — BLOCKED(需真机)
- 步骤：连续说 3 句，句间各停 2s，全程不点结束。
- 预期：3 段按说话顺序（FIFO）依次润色上屏，无乱序/丢段/重复；界面始终 Recording。

### N4-010 [P0] 点击结束控件才停录并收尾
- 步骤：录音中（可正在说话）点击「结束」控件。
- 预期：立即停录；尾巴（未定稿部分）入队润色上屏后收尾，回到键盘界面。真实尾巴内容验证 **需真机**；模拟器验：点结束 → 状态机退出 Recording → 回键盘不卡死。

### N4-011 [P1] 空尾巴但已有分段：安静回键盘 — BLOCKED(需真机)
- 步骤：说一句 → 停 2s（分段已上屏）→ 不再说话 → 点「结束」。
- 预期：无多余空白/重复上屏，安静返回键盘，已上屏内容保留。

### N4-012 [P0] 「取消」丢弃未上屏分段
- 步骤：录音中点击「取消」。
- 预期：立即停录回键盘；未上屏的分段/尾巴全部丢弃，文本框不出现新内容。已上屏分段不回滚。含真实分段的丢弃验证 **需真机**；模拟器验空会话取消不崩溃、不上屏。

### N4-013 [P0] 切 App / 收键盘 / 失焦立即停录
- 步骤：录音中分别执行：a) Home 键切走；b) 收起键盘（返回键）；c) 点击其他输入框外区域使失焦。每次重新进入录音再测下一项。
- 预期：三种情况均立即停止录音（不后台继续收音）；返回宿主 App 后键盘可正常再次呼出与录音。

### N4-014 [P1] 无语音直接点结束（空会话）
- 步骤：进入录音界面 → 不发出任何声音 → 直接点「结束」。
- 预期：正常退出回键盘，不上屏任何内容，无崩溃/无卡转圈；提示音行为符合设定。

### N4-015 [P1] 分段定稿后字幕清空续听 — BLOCKED(需真机)
- 步骤：说一句 → 停 2s → 观察字幕区 → 再说下一句。
- 预期：定稿瞬间字幕区清空；下一句字幕从头开始渲染，不残留上一句文本。

### N4-016 [P2] 长时间连续录音稳定性
- 步骤：保持录音界面 Recording ≥3 分钟（模拟器静默即可）。
- 预期：界面不自动退出、不 ANR、不崩溃；点结束仍能正常收尾。多段真实转写的长会话 **需真机** 复验。

## F 组：D-1 回归（IME 初始化期 ANR + 错路由）— r2 新增

> 背景：r1 发现 D-1（冷启动重初始化 1–2 分钟满载 → ANR、Extension not found 覆盖层、点中/英误开历史、话筒无响应）。修复：①ZipformerController/RealSpeechEngine 模型加载线程降 THREAD_PRIORITY_BACKGROUND；②ExtensionManager.getExtensionById 直读三个源索引 StateFlow 消除竞态。以下用例验证修复效果。

### N4-D1-01 [P0] 冷启动立即输入不 ANR
- 前置：`am force-stop com.wordtaker.keyboard.debug`，logcat 已清。
- 步骤：force-stop 后立即在宿主输入框呼出键盘，并在初始化窗口内高频操作（连续打字≥20 键）。
- 预期：logcat 无 `ANR in com.wordtaker`、无 FATAL；/data/anr/ 无新增 wordtaker 记录；触摸事件 5s 内均有响应。

### N4-D1-02 [P0] 初始化期点「中/英」不误开历史面板
- 步骤：force-stop 后键盘刚渲染的最初几秒内，反复点「中/英」切换键。
- 预期：只做中英切换（键面高亮变化），不弹出历史记录面板，历史条目不上屏。

### N4-D1-03 [P1] 初始化期话筒可用或明确置灰
- 步骤：force-stop 后键盘刚渲染的最初几秒内点「话筒」。
- 预期：要么进入录音界面，要么按钮明确置灰/提示加载中；不允许「看似可点但无任何响应」。

### N4-D1-04 [P0] 无 Extension not found 覆盖层
- 步骤：force-stop → 呼出键盘 → 观察渲染全程（含 logcat）。
- 预期：不出现 devtools 覆盖层/`IllegalStateException: Extension … not found`；键盘布局一次渲染正确、无手写面板错版。

### N4-D1-05 [P0] force-stop 连杀 3 轮稳定
- 步骤：N4-D1-01~04 的流程连续执行 3 轮（每轮 force-stop → 立即呼出 → 高频操作打字/中英/话筒）；另做一轮 60 秒连续点击锤测。
- 预期：3 轮 + 锤测全程无 ANR、无 FATAL、无 not found、无进程反复被杀（pid 除 force-stop 外不变）。

### N4-D1-06 [P1] 初始化完成后全功能正常
- 步骤：最后一轮初始化完成后（CPU 回落），做核心功能回归：中文打字上屏、英文、符号页、话筒录音进出。
- 预期：全部正常，与健康态无差异（修复不引入功能回归）。
