# TC-20260714-batch3 · 第三批 4 项改动测试用例

- 日期：2026-07-15
- 被测包：com.wordtaker.keyboard.debug（已装为默认 IME，emulator-5554，原生分辨率 1080x2400）
- **执行前置（每次必查）**：`adb shell wm density` 必须为 480（仿真 vivo iQOO 8）；不是则 `adb shell wm density 480`。A 组双密度用例按用例内指示临时切 420，测完必须恢复 480。
- 执行注意：模拟器 `input tap` 约半数丢事件，一律用同点 50ms 短 swipe 代替 tap；**禁止 pm clear**。
- 判定工具：截图像素测量（`adb exec-out screencap -p`）、`dumpsys window`、logcat、`run-as` 读私有文件。
- 标注「需真机」的用例模拟器不可验或只可部分验。
- 屏宽 W=1080px（两种密度下物理像素不变，比例目标均以 px/W 计）。

## 一、改动 A · 尺寸比例化（1:1 根治）

**B3-001 480dpi 全指标比例量化** · P0
- 前置：density=480；中文 QWERTY 拉起键盘，截图。
- 步骤：像素测量：①单行行高（相邻两行键帽顶边 y 差）；②顶栏（候选/工具条）高度；③键水平间距（相邻键帽间隙）；④键盘底部到屏幕底边的底隙。各除以 W=1080 得比例。
- 预期：行距/W≈0.1485、顶栏/W≈0.152，均在目标 ±2% 内；键距、底隙与代码常量（WT_*_RATIO、FIXED_BOTTOM_GAP_RATIO）折算值 ±2% 内；无键帽重叠/裁切。记录全部实测值供 B3-003 对比。

**B3-002 字母 glyph/键帽 0.40（双密度）** · P1
- 前置：同 B3-001，分别在 480 与 420 各截一次 QWERTY。
- 步骤：放大量测任一字母键（建议 F/H）：glyph 字高 px ÷ 键帽高 px。
- 预期：两密度下均 ≈0.40（±2%）；26 键字号一致，无溢出。

**B3-003 420dpi 全指标 + 双密度一致性** · P0
- 前置：`adb shell wm density 420`，重新拉起键盘（必要时收起重开）。
- 步骤：重复 B3-001 全部测量；逐项与 B3-001 的 480 实测比例对比；测完 `wm density 480` 恢复并确认。
- 预期：420 下各比例仍中目标 ±2%；480 与 420 同项比例差 <2%（比例化生效，非 dp 硬编码）；恢复 480 后布局回到 B3-001 状态。

**B3-007 「12·34」计算器页布局抽测 + 上屏** · P0

- 预期：布局与规格一致；抽测键全部正确上屏；高块键（⌫/./换行）点击热区完整（上下缘各点一次均响应）。

**B3-008 「符号」页布局抽测 + 上屏** · P0
- 前置：进入符号页，截图。
- 步骤：核对：`_—;#%&^*+=` 行 / `-\/:~()…@""` 行 / [123][标点区][⌫] 行 / 底部分类行 [←][时钟][中][EN][[]][¥][数][(-)][①]。抽测 ≥8 键：`_`、`#`、`^`、`=`、`&`、任一标点、⌫、[123] 跳转、← 返回。
- 预期：布局与规格一致；抽测键全部正确上屏/生效；← 呈绿色。

**B3-009 8 分类逐个切换与上屏** · P0

- 预期：8 个分类全部真实可切换（内容区随之变化，非占位）；当前分类绿色高亮且唯一；每类抽测符号正确上屏。

**B3-010 时钟 MRU 最近使用 + 持久化** · P1
- 前置：符号页。
- 步骤：①在「¥」类上屏 1 个符号、「①」类上屏 1 个符号；②切到「时钟」分类查看；③收起键盘、切走再切回 IME（或 `am force-stop` 后重拉键盘，不 pm clear），再进时钟页。
- 预期：②中两个刚用过的符号出现在最近区且序合理（最新在前）；③重建后 MRU 仍在（wt_sym2_recent.txt 持久化生效）。

**B3-011 三页顶边像素恒等** · P0
- 前置：依次进入「123」页、计算器页、符号页，各截一屏。
- 步骤：量测每页键盘区顶边 y 坐标（含顶栏则量顶栏顶边，三页取同一基准线）。
- 预期：三页顶边 y 完全相等（基准 ≈1409，此前实测值），互差 0px；与字母页切换往返亦无跳动。

**B3-012 快速连续切页 10 次高度不变** · P1

## 四、改动 D · 录音重做（后台转写 + 多段并行）

**B3-013 录音中停顿不显字幕** · P0 · 部分需真机
- 前置：拉起键盘，点说话开始录音。
- 步骤：保持静默 >3s，观察录音界面；再（真机）说一句话后停顿 >3s 再观察。
- 预期：全程**不显示字幕**、不上屏任何文字；界面仅有猫 +「正在倾听…点击结束」。模拟器可验静默场景；说话后停顿场景需真机。

**B3-014 点结束→立即可开新段（多段并行）** · P0 · 需真机
- 前置：录音中（已说一句话）。
- 步骤：点「结束」；**立即**再点说话按钮开始第 2 段并说话；观察第 1 段是否在后台转写润色并上屏。
- 预期：点结束后说话按钮立即可用（无需等第 1 段出字）；第 1 段结果稍后自动上屏；第 2 段录音不受影响。

**B3-015 猫头×N 后台处理角标** · P1 · 需真机
- 前置：接 B3-014 造出 ≥2 个后台处理中的段（连续快说快结束）。
- 步骤：观察猫头角标数字随队列变化；等全部上屏后再看。
- 预期：角标显示「×N」= 当前后台处理段数，随完成递减；队列清空后角标消失。

**B3-016 取消只弃当前段** · P0 · 需真机
- 前置：第 1 段已结束进入后台处理，第 2 段正在录音。
- 步骤：对第 2 段执行取消。
- 预期：仅第 2 段被丢弃（不上屏）；第 1 段照常完成上屏；取消后可再开新段。

**B3-017 收键盘：停当前段、队列段完成** · P0 · 需真机
- 前置：第 1 段后台处理中，第 2 段录音中。
- 步骤：直接收起键盘（返回键/切走输入框）；稍候重新拉起键盘查看输入框。
- 预期：第 2 段（录音中）被停止丢弃；第 1 段（队列中）仍完成并上屏；无崩溃、无残留录音状态。

**B3-018 连续 3 段 FIFO 顺序上屏** · P0 · 需真机
- 前置：空输入框。
- 步骤：连续录 3 段内容可区分的话（如「第一段」「第二段」「第三段」），每段说完即点结束并立刻开下一段。
- 预期：3 段全部上屏且顺序严格 1→2→3（FIFO），不交叉、不丢段；文本经润色但语义对应各段。
