## TC 外新缺陷（本轮最重要发现）

**【P0】App 设置页（SettingsLauncherAlias）主线程重负 → 滚动触发 ANR → 进程被杀 → 用户设置丢失/回滚**

- 复现 3 次：①~02:08 设置页滚动后被顶掉（当时误判为导航）；②03:06 `Killing …debug (adj 0): user request after error`；③03:09 明确 ANR：`Input dispatching timed out … Waited 5052ms for FocusEvent`，`spent 20933ms processing MotionEvent(ACTION_UP, (540,900))`，进程 CPU 125%，被 Force finish + kill。
- 启动也慢：二次打开 splash 停留 >8s，`Choreographer: Skipped 758 frames`。
- **二次伤害（用户可感）**：ANR 杀进程导致设置写入丢失——云词库曾出现「UI 已拨到开、pref 仍 false」；提示音音量 58% 在进程重启后回滚显示 1%。
- 键盘 IME 本体（FlorisImeService）不受影响（B3-023/024 全绿）；问题仅在 App 设置 Activity。
- 建议：优先排查设置页 Compose 首帧/滚动时主线程同步重活（额度拉取? 模型/文件 IO?），修复后重跑 B3-021/022 持久化链路。
