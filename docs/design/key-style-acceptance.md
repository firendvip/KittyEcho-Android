## 主观质感评分（锚：微信键盘 = 8.6）

**8.1 / 10**

1. 键帽质感与排布已接近微信：Medium 字重 + 6/9dp 间隙节奏 + 精准的夜间三层色阶，键盘"贴纸感"基本消除，但日间键底投影仍偏含蓄，立体感比微信差半档。
2. popup 是本轮最大跃升：脱离式气泡 + 放大字符 + 入出场动画 + 边缘钳位全部成立，唯气泡偏矮、悬浮高度偏大，比 Gboard/微信的"贴键浮起"少一点精致感。
3. 动效与夜间已属第一梯队水准（瞬时按压/120ms 回落/功能键回弹、夜间色板逐值命中），差距集中在细节打磨：空格无涟漪、chevron 与 123 键仍打架、候选栏视觉平淡。
